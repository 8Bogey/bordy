# مراجعة أمن الترخيص — بوردي

استخدمها عند تعديل أي ملف في `app/src/main/java/com/bordy/app/license/` أو `app/src/main/java/com/bordy/app/sync/` أو `bordy-license/src/{handlers,account,admin}`.

## التحقق المحلي

- [ ] الرمز يُتحقق من توقيعه ECDSA P-256 بالمفتاح العام فقط؛ لا يوجد مسار «ثقة بالخادم» بلا توقيع.
- [ ] بصمة الجهاز مضمّنة في الرمز ويُقارن بها.
- [ ] `ClockGuard` يغطي: تقدم الوقت، الرجوع، تغيير المنطقة الزمنية، إعادة التشغيل.
- [ ] `IntegrityChecks` لم تُضعف (توقيع الحزمة/الشهادة).
- [ ] حالة `EXPIRED` تقفل الوظائف فعلياً، وليست مجرد شاشة تنبيه.

## الخادم

- [ ] لا يُقبل `device_id` أو `exp` من العميل دون تحقق.
- [ ] التجربة تُسجَّل خادمياً ولا تُعاد بمسح بيانات التطبيق.
- [ ] `/v2/*` و`/admin` بلا CORS مفتوح للتوكنات.
- [ ] مقارنة الأسرار عبر `timingSafeEqualString`.
- [ ] حدود المعدل مفعّلة على المسارات الحساسة (activate/refresh/orders/codes).
- [ ] كل رقم خارجي يُمرّر على `Number.isFinite` قبل مقارنته: `undefined < n` يساوي `false`، فالحقل الناقص يمر بصمت (بوابة ترقيات المزامنة كانت كذلك).
- [ ] البوابات تفشل مغلقة: الطلب الناقص أو السيئ يُرفض، ولا يُفسَّر الغياب على أنه «مقبول».
- [ ] لا تسريب تفاصيل داخلية في رسائل الخطأ (تظهر `error` عامة + `code` ثابت).

## الأسرار والتوزيع

- [ ] لا مفاتيح خاصة أو كلمات مرور في git أو الكود أو الوصف.
- [ ] R8 يحمي `com.bordy.app.license.**` (راجع `proguard-rules.pro`).
- [ ] نسخة release موقّعة بنفس المفتاح ومطابقة لـ `EXPECTED_CERT_SHA256`.

## المزامنة

- [ ] النقل لا يمسح الجهاز القديم قبل تنزيل الجديد كاملاً.
- [ ] التعارضات تُحفظ وتُعرض (لا last-write-wins أعمى).
- [ ] الحذف عبر tombstone، ولا حذف صفوف من الخادم بناءً على جهاز غير نشط.
