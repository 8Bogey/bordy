# الأمان والترخيص

- الترخيص يُتحقق محلياً بتوقيع ECDSA P-256. ممنوع إضعاف `LicenseManager`، أو تجاوز `IntegrityChecks`، أو إضافة مسار يفتح التطبيق بلا ترخيص صالح.
- مفاتيح التوقيع الخاصة (`ec_priv_k1_pkcs8.pem`, `ec_priv_k2_pkcs8.pem`) وكلمات الـ keystore وأسرار الأدمن: ممنوع قراءتها أو طباعتها أو نسخها أو رفعها. لا تُعدّل `admin_secrets.txt` أو `keystore_info.txt`.
- لا تُضِف مفاتيح أو DSNs أو كلمات مرور في الكود أو `build.gradle.kts` أو ملفات الاختبار؛ استخدم `wrangler secret` أو متغيرات بيئة محلية مُهمَلة.
- لا تضعف `ClockGuard` ولا تعتمد على وقت الجهاز وحده.
- البصمة/البيومترية: لا تتجاوز `Biometrics.kt` ولا تُخزّن بيانات بيومترية؛ فقط نتائج المصادقة.
- الحزم الموقّعة: `EXPECTED_CERT_SHA256` في `app/build.gradle.kts` مرجع سلامة — لا تغيّره دون إعادة توقيع مقصودة.
- R8/minify: أي حزمة تعتمد على الانعكاس (Room، الترخيص) تحتاج قاعدة keep صحيحة في `app/proguard-rules.pro`. تحقق من أسماء الحزم الفعلية (`com.bordy.app.*`) لا القديمة (`com.mubtaker.*`).
- لا تشغّل `git push` أو تنشر Worker أو تبني نسخة release موقّعة دون طلب صريح.
- عند اكتشاف تسريب محتمل: أوقف، تحقق من الدليل، أبلغ المستخدم بالتفاصيل ومستوى الخطورة قبل أي إجراء.
