# DECISIONS — قرارات معتمدة

> مستقاة من `LICENSING_PLAN.md` و`ACCOUNT_SYNC_PLAN.md` و`plan.md`. أي تغيير هنا يحتاج موافقة المستخدم.

## الترخيص والاشتراك

| القرار | القيمة |
|---|---|
| التجربة المجانية | 7 أيام، تُسجَّل على الخادم بأول اتصال (لا تعود بإعادة التثبيت) |
| الأسعار | شهري 7,500 — 3 أشهر 20,000 — سنوي 70,000 د.ع |
| طرق الدفع | آسيا باي، زين كاش، كي كارد، FIB (تحويل يدوي برقم مرجعي) |
| عند الانتهاء | قفل كامل، بلا تصدير نسخة احتياطية |
| مدة السماح | يومان؛ أقصى عمل أوفلاين 7 أيام |
| جمع الاسم/الهاتف | اختياري عند التجربة، إلزامي عند الدفع |
| الدعم | تيليجرام + واتساب |
| شروط الخدمة | شاشة إلزامية عند أول فتح، تُدار من تيليجرام/لوحة الأدمن |
| Key Attestation | غير منفَّذ (الجهد لا يبرّر الفائدة) |
| الترحيل | Migration صريح + نسخة احتياطية تلقائية قبل الترقية؛ لا `fallbackToDestructiveMigration` |
| التوزيع | APK مباشر عبر GitHub Releases + تيليجرام؛ بلا Google Play |
| التكلفة | صفر (خطة Cloudflare المجانية)، هدف ~500 مشترك |
| التوقيع | ECDSA P-256، مفتاحان K1/K2، تحقق محلي بلا إنترنت |

## الحسابات والمزامنة

| القرار | القيمة |
|---|---|
| الحساب | حساب واحد، جهاز مزامنة نشط واحد |
| مصدر الحقيقة | الخادم مشترك؛ Room مصدر الواجهة (offline-first) |
| المزامنة | تلقائية بعد التعديل، عند عودة الشبكة، عند الفتح، ودورياً بالخلفية |
| الصور/الفيديو/URI/سجل النشاط | محلية فقط، لا تُرفع |
| تعديلات الأدمن | تمر عبر محرك المزامنة نفسه |
| التعارض | يُحفظ ويُعرض، لا أولوية عمياء ولا طمس |
| النقل بين الأجهزة | تنزيل كامل + تأكيد سلامة قبل مسح القديم |
| انتهاء الاشتراك | قفل فقط، البيانات تبقى محفوظة |
| كلمات المرور | لا تُخزَّن ولا تُعرض أبداً (pepper + hash) |
| الاستقصاء | متكيف: 60 ثانية نشط → 5 دقائق خامل؛ لا polling كل 10 ثوانٍ |
| معرّفات المزامنة | `sync_id` عشوائي ثابت عالمياً + `id` محلي رقمي |
| معاملة الكتابة | كتابة محلية + طابور المزامنة في معاملة Room واحدة |

## المجال والتسعير

| القرار | القيمة |
|---|---|
| سعر البيع الافتراضي | من المخزون (`ComponentVariant.defaultSellPrice`) |
| العنصر اليدوي | يحمل سعره المحفوظ |
| تكلفة العمل | تُجمع مع البيع لحساب إجمالي البورد/القالب |
| تقريب الأسعار على الخادم | إلى أقرب 250 د.ع |
| بيانات المستخدم القديمة | لا تُهاجَر تلقائياً إلى نماذج جديدة |
